```

  → 文件内 3-gram Jaccard 去重 3721→3720（剔 1 条同 id 同文）
  → 金标 seed500_final 跨库去重（0 重复 / 0 冲突，最大相似度 0.125，无泄漏）
  → 元评论剔除 3720→3683（hard 2 + soft 35，其中 28 条为「【模拟文本，非真实…】免责头」）

  → SimHash 64-bit 近重复去重（Hamming ≤6）：0 命中——六批间无洗稿级近重复；
    59 条同 id 异文加 #dupN 后缀保 id 唯一
```
