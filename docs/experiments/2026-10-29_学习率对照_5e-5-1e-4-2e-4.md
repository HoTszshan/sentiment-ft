# 实验报告：学习率对照（5e-5 / 1e-4 / 2e-4）

**日期**：2026-10-29
**基座**：Qwen3-4B-Instruct-2507（Non-thinking）
**数据**：round0 750 条（train 673），9:1 anchor 混入（与后续主线一致）
**训练**：LoRA r=16 / α=32，cosine，有效 batch 8，3 epoch = 255 步；仅学习率一档不同
**评测**：`gold500_test.jsonl`（500 条），模式 B，统一 strict 分母口径

> 本报告回答一个问题：**LoRA 微调的学习率选多大？** 下界（5e-5）与上界（2e-4）各架一枪，
> 与 1e-4（POC 消融胜者 R2 的配置）三点连线。

---

## 1. 实验目的

1. **框定下界**：5e-5 是否已经小到学不动（欠拟合）？
2. **框定上界**：2e-4 内容指标是否更高？若是，格式契约是否守得住？
3. 依据「主指标不降、格式门不破」选出定稿学习率，同时满足「GRPO 起点要稳」的下游要求。

---

## 2. 方案设计

| 组 | 学习率 | 其余配置 |
|---|---|---|
| **R4** | **5e-5** | POC2 骨架掩码 / 3 epoch / anchor 0.1 / 与 R2 完全一致 |
| **R2**（基线） | **1e-4** | 同上 |
| **R5** | **2e-4** | 同上 |

## 4. 发现与结论

### 4.1 下界：5e-5 欠拟合，明确排除

R4 的 train_loss 只压到 1.073（R2 为 0.951），val_loss 0.854 也最高。全部内容指标垫底
（hard_case 52.51，比 R2 低 6.6pp），格式指标同样最弱。学习率太小时 255 步内模型没有
吸收完 673 条的信号，各字段同时欠拟合。

### 4.2 上界：2e-4 内容更强，但格式契约崩溃

R5 的内容指标是本组最高：hard_case 61.12（比 R2 高 2.0pp）、sent 92.44、FAR 11.11。
但 **JSON 合法率跌至 92.2%（46 条解析失败）、evidence 子串跌至 91.8%**——
距 99.8% 门限差 7.6pp，属一票否决级劣化。

机制：学习率过大时每步参数更新幅度大，闭集枚举 token 的输出分布在高频更新下抖动，
JSON 的语法完整性最先受影响；evidence 作为长自由文本字段对分布抖动同样敏感。
R5 的 46 条格式失败以截断与语法错乱为主（幸存样本分数存在幸存者偏差，真实全口径更差）。

val_loss（0.7796）虽然最低，但 val_loss 衡量的是加权 loss，**不能反映格式稳定性**——
这与 2026-10-24 报告「loss 曲线不能判断格式是否学会」的结论一致，也是格式 canary
与 gate4 门存在的理由。

### 4.3 判定

**LR = 1e-4 定稿。** 三点连线呈倒 U 形：5e-5 欠拟合、2e-4 格式崩、1e-4 同时是内容分与
格式分的平衡点。附带两条：

1. **gate4 门的价值在本组得到直接验证**：若只看主指标 F1，R5（61.12）会被误选；
   JSON 92.2% 的一票否决把它拦下。后续 R6-a005（97.2%）再次出现同类情况。
2. **与 GRPO 的衔接**：1e-4 是「内容与契约」的平衡点，输出分布稳定，作为 RL 起点
   比一个内容略高但格式脆弱的起点更合适——RL 阶段的采样分布噪声会叠加在 SFT 端点上。

### 4.4 ROI 口径

R4/R5 的 FAR 分别为 13.5% / 11.1%，R2 为 12.9%：学习率对业务成本的影响同样在噪声内，
本组结论不影响 ROI。学习率的作用体现在「能不能稳定交付格式合规的模型」，
不体现在负向识别的成本上。
