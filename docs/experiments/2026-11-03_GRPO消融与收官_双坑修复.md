# 实验报告：GRPO 消融与收官——reward 三维归因 + 双坑修复

**日期**：2026-11-03
**起点**：SFT 胜者 R7-ep4（merged bf16，negR 98.80 / negP 89.62 / risk 78.20 / CoT p50 273 token）
**方法**：GRPO（TRL 0.14，LoRA r16），lr 2e-5 / β_KL 0.04 / G=4 / T=0.7 / **1 epoch**（epoch 消融结论复用）
**池**：`grpo_train_prompts_final.jsonl`（1877 条，negative 40.2%，盲区 pn 46 / cf 163）
**评测**：`evaluate_sft.py` 模式 B，金标 = gold500_test（500 条纯人标，negative 166）
**前情**：基准与盲区补齐见 `2026-11-02_GRPO两轮_基准与盲区补齐.md`（G1/G1'/G1'' 三枪 + T4）；
本报告覆盖收官阶段——G2（KL 消融）、G5a/G5c（reward 归因）、G6（k 迁移收口）、epoch 消融。

## 1. 一句话总结

GRPO 实验线收官。**G2 拿到「KL 必要性」的硬实证**（β=0 下 88 步 KL 指数发散至 2.8×10³⁴ →
NaN 坍塌，并顺带揪出 eval 权重同步盲区）；**G5a/G5c 把每一维 reward 的「有/无」差值全部
量出来**（关 R_length → CoT 回弹 +36% 归因实锤，且发现「压短顺带抑制过度判负」的新结论；
risk 部分匹配档 → SubAcc +0.6pp）；**G6 证明「把不会的学会了」**（k=4 +15.8%，盲区桶 77~78%
全对）。Base → SFT → SFT+GRPO 三行数字 + 三份消融证据，面试弹药全部有 run 目录级实证。

## 4. 三条消融结论（每条都有「有/无」差值背书）

### 4.1 G5a：CoT 压缩归因实锤 + 压短的隐藏红利

- **归因**：关掉 R_length 后 CoT p50 230 → **313（+36%）**、p95 329 → 436，且训练期
  completion_length 全程不收窄（对照 379.7→310）——**CoT 压缩是 R_length 的功劳，
  不是 SFT 遗产**。简历口径「GRPO 压短 CoT −19~32%」拿到消融证据；
- **新结论**：无压短力时 negP −4.3pp / FAR +4.3pp（12.70%）——**更长的 CoT 让模型更敢判负**。
  R_length 的压短不仅省推理成本，还顺带抑制过度判负。**「CoT 长度 ↔ 判负倾向」正相关**
  是本实验线新挖出的可复述机制结论；
- 面试一句话：「我们试过关掉长度奖励重训——CoT 回弹 36%，同时误报率涨 4.3pp；
  长度塑形是在拿推理成本换判负纪律，这是金标上量出来的取舍。」

### 4.2 G5c：risk 部分匹配档——「子集错 ≠ 全错」给出梯度

- **改动**：`r_accuracy` 的 risk 未中区插 `0.5 + 0.2×Jaccard(g_rk, p_rk)`（交集>0 才生效），
  单调链 `0.5 < 部分档 < 0.7 ≤ 1.0` 不破；
- **收益**：risk SubAcc 77.80 → **78.40**（> 77.60 判据线），compliance F1 **+5.2**（71.23→76.47）
  为最大单类增益；negR 顶到 **99.40**（历史最佳，唯一漏报 = idx 467 能力边界）；
- **代价**：negP −2.9 / FAR +2.9——部分档让模型更敢标 risk，**P/R 权衡点右移**；
- **口径**：按「negR>negP>risk」现行业务优先级，主数字仍以 G1'' 为准，G5c 记为
  「risk 维度可插拔配置」——若业务侧 risk 权重上调，此开关一行环境变量即可启用。

### 4.3 G2：撤 KL = 88 步内数学死亡（奖励坍塌标本）

时间线（`run_20261103_103528_G2p2_ep1_kl0`，逐步实测）：

| 阶段 | step | KL | grad_norm |
|---|---|---|---|
| 健康 | 1~15 | ~0.0005 | 0.1~0.2（正常） |
| 漂移启动 | ~16 | 0.002 → **1.45** | 仍温和 |
| 指数发散 | 22~88 | 33 → 2.4e8 → **2.8e34** | 仍 ≤1.3（被截住） |
| **NaN 坍塌** | **89** | **inf** | **nan** |
| 死寂 | 90~234 | nan | nan（145 步空转） |

- **关键区分**：梯度截断管单步，KL 阻尼管累积——max_grad_norm 拦不住方向一致的小步复利；
- **奖励坍塌 ≠ reward hacking**：坍塌时 reward/loss 全程「正常」（loss 还「收敛」到 1.6e-10），
  唯一前兆是 **KL 步间跳变**。判训练死活，别看 reward，看 KL；
- **结论**：β_KL=0.04 保留。trl 0.14 无 clip 变体里 KL 是唯一策略约束，撤掉即死。

## 5. 双坑发现与修复（G2 的意外收获，工程价值 ≥ 消融本身）

### 坑 A · eval 权重同步盲区（PEFT + vLLM）

- **现象**：历代训练 eval 分数 run 内恒定（G1 恒 0.5563 / G1'' 恒 0.3469 / G2 恒 0.3469）
  ——熔断器全程量的是裸基座；
- **根因**（实验证实）：PEFT `state_dict()` 里 base_layer = 冻结基座原值，LoRA 增量在独立
  `lora_A/B` 键；vLLM `load_weights()` 按名字加载，lora 键无对应参数被**静默忽略**；
- **修复**（`lib/grpo_eval_fuse.py`）：merge_adapter → 同步 → unmerge_adapter 三步；
  **G5c/G5a 真机验证生效**（baseline 0.3584 / 0.1963，均 ≠ 0.3469，eval 从此量真实策略）；
- 附带：eval 指标接入 `trainer.log`（`eval/reward_mean`），wandb 可视化补齐。

### 坑 B · 熔断器无数值健康判据

- **现象**：G2 NaN 坍塌后 145 步空转无人拦（eval 瞎 + 无 KL 判据 + 无 NaN 早停）；
- **修复**：新增数值健康熔断（`GRPO_NAN_FUSE=1`），每步检查三判据：KL 持续超限
  （连续 3 步 >10 停车）、KL 跳变（只告警不停车——防 G1'' 式孤立尖峰 1285 误杀）、
  grad_norm/loss 连续 NaN ≥3 步停车；五场景模拟全过（孤立尖峰不误杀、持续发散必停）；
- **真机验证**：G5a/G5c 全程 0 触发（KL 峰值 0.275/0.549），防线在位且无误杀。

### 防线正确工作的正面记录

G2 NaN adapter 在 merge 时被 parity gate 拦截（`lora_B.absmax = nan` vs 健康 0.002）——
最后一道防线把崩坏权重挡在生产之外。

## 8. 结论与遗产

### 8.1 最终成绩单（Base → SFT → SFT+GRPO）

| 指标 | Base（E3） | SFT（R7-ep4） | **SFT+GRPO（G1''）** | GRPO 净增益 |
|---|---|---|---|---|
| sentiment Macro-F1 | 80.79 | 94.69 | **94.81** | +0.12 |
| negative_recall | 99.40 | 98.80 | **98.80** | 0（回标） |
| negative_precision | 65.74 | 89.62 | **92.13** | +2.51 |
| false_alarm_rate | 34.26% | 10.38% | **7.87%** | **−2.51pp** |
| risk SubAcc | 52.80 | 78.20 | 77.60 | −0.60 |
| CoT token p50 | 488 | 273 | **220** | **−19.4%** |
| JSON / ev 子串 | 0 / — | 100 / 99.6 | **100 / 100** | 全绿 |
| 契约违规条数 | 500 | 20 | **2** | −90% |

### 8.2 已确认的结论（全部有消融/对照证据）

1. **KL 必要性**：撤 KL → 88 步 NaN 坍塌（G2 双 run）；β=0.04 保留；
2. **CoT 压缩归因**：关 R_length → p50 回弹 36%（G5a）；压短还顺带抑制过度判负；
3. **risk 部分匹配档有效**：+0.6pp SubAcc，可插拔（G5c）；
4. **盲区补齐因果链**：池分布 → k 迁移（+15.8% k=4）→ 考卷转正（G1''/G6）；
5. **1ep 收敛**：1877 大池 2ep 无净收益（epoch 消融）；
6. **重跑方差 ±1.2pp**：判别侧结论在考卷分辨率内稳健（两次独立训练）。

### 8.3 工程遗产

- eval 权重同步修复 + eval 指标进 wandb（`grpo_eval_fuse.py`）；
- NaN/KL 数值健康熔断（五场景验证）；
- `GRPO_DISABLE_R_LENGTH` / `GRPO_RISK_PARTIAL` 消融开关（环境变量，默认关零影响）；
- 踩坑笔记 `docs/GRPO踩坑笔记.md`（奖励坍塌 + eval 盲区 + merge 拦截三条）。

### 8.4 未做与理由

| 项 | 状态 | 理由 |
|---|---|---|
| G3（lr 5e-5） | 砍掉 | G2 已实证坍塌开关在 KL 不在 lr；预测性实验 ROI 低 |
