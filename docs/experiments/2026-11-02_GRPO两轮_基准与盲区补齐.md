# 实验报告：GRPO 两轮训练——从「策略没动」到「盲区补齐」

**日期**：2026-11-02
**起点**：SFT 胜者 R7-ep4（merged bf16，negR 98.80 / negP 89.62 / risk 78.20 / CoT p50 273 token）
**方法**：GRPO（TRL 0.14，LoRA r16），lr 2e-5 / β_KL 0.04 / G=4 / T=0.7 / 2 epoch
**评测**：`evaluate_sft.py` 模式 B，金标 = gold500_test（500 条纯人标，negative 166）

---

## 1. 一句话总结

GRPO 两轮共四枪。第一轮（G1/G1'）判别侧变化全部落在 500 条金标的置信区间内，
但过程指标实锤：**CoT 压短、契约违规 −90%、负向误报率 −2.4pp**；
第二轮（G1''）定位并补齐「训练分布 ≠ 考卷分布」的病根后，
**负面召回回标 98.80（漏报 4→2，盲区靶点 3/4 修复）**，同时保住全部过程收益——
CoT 压至 220 token（−19.4%，四轮最低）、evidence 子串 100%、契约违规仅 2 条。

## 4. 关键发现：漏报 4 条的病因链与修复

### 4.1 病因定位（G1' 后逐条比对）

G1' 漏报的 4 条 negative，**全部是 relevance=passing**（目标主体仅被顺带提及的负向场）：

| idx | 题面特征 | 模型行为 |
|---|---|---|
| 275 | 深蓝 SL03——投诉主体是极氪 001，深蓝「同行案例」带过 | 判 neutral |
| 277 | 融创——名单末尾被点名，投诉主体是小区物业 | 判 neutral |
| 423 | 格力——行业「套路降价」长文里一句带过 | 判 neutral |
| 467 | 保利——「幸亏当初没碰保利的盘」反事实 | 判 positive |

**433 训练池里这类题只有 5 条（1.2%），而考卷里占 negative 的 13.9%**——
训练分布里「主角不是我、负向是别人的、我只被捎带」这类题几乎缺训。
漏报集中在它身上不是巧合。

### 4.2 对症下药：round2 数据三件套

| 动作 | 结果 |
|---|---|
| 新语料 rl_v2_golden（4912 条，合议庭门禁） | 对 SFT / gold500 零交叉 ✅ |
| 全量 G0 k 筛（4612 条，2×3090 各 45min） | keep 1306（28.3%），negative 占 35.5% ✅ |
| 盲区 k=4 白名单（全对也喂） | +115 条 |
| 盲区 k=0 补捞（全错也给机会） | +23 条 |
| **最终冻结池** | **1877 条，negative 40.2%** |

盲区题型在池量变化：

| 题型 | 433 池 | 1877 池 | 考卷占比 |
|---|---|---|---|
| passing×negative（顺带提及型） | 5 | **46** | 23/166 |
| counterfactual×negative（幸亏没X） | 39 | **163** | — |

### 4.3 修复验证：靶点逐条转正（G1'' 最硬的因果证据）

| idx | 题型 | SFT | G1 | G1' | **G1''** |
|---|---|---|---|---|---|
| 275 | passing×neg | ✗ | ✗ | ✗ | **✅ negative** |
| 277 | passing×neg | ✓ | ✓ | ✗ | **✅ negative** |
| 423 | passing×neg | ✓ | ✗ | ✗ | **✅ negative** |
| 467 | cf×passing | ✗ | ✗ | ✗ | ✗（能力边界，新漏 396 抵平） |

**盲区题型入池 → 3/4 靶点直接修复**：这是「病根→对症→兑现」的完整因果链，
不是指标涨落的相关性。剩余漏报 idx 467（反事实当真夸）+ 新增 idx 396，共 2 条，
与 G0b「k=0 残留 15 条判能力边界」相互印证。

## 5. 踩坑记录

| 坑 | 现象 | 根因与修法 |
|---|---|---|
| **保守漂移** | G1' 比 SFT 多丢 2 条（negative 滑到 neutral） | 难题池放大「宁判 neutral 不判负」；盲区题型入池后修复 |
| **k 筛盲区** | 简单负向题 k=4 全被筛掉 | k 筛按整体 reward 筛，看不见「提及位置」维度；白名单是唯一规则修改点 |
| **rows idx 错位** | 两份探针明细合并出现 694 条假重复 | `idx` 只在各自分片内有效；必须分区配对后再合并 |
| **吞吐外推翻车** | 预估 25h，实跑 7.5h | 旧基准混入了串行 eval 开销；eval 改 vLLM 独立卡后，单步只剩采样+训练净时间，跨机先实测校准 |
| **id 查重无效** | 新旧数据 id 前缀不同（rl- vs rl3-），比 id 必然全零 | 查重以正文指纹（去空白 md5）为准 |

## 6. 结论与下一步

### 6.1 已确认的结论

1. **GRPO 的本职收益全部兑现并保持**：CoT 压短 19.4%、契约违规 −90%、误报率 −2.51pp、evidence 100%；
2. **盲区修复因果成立**：negR 回标 98.80，4 条漏报靶点 3/4 直接转正——「训练分布对齐考卷分布」是有效杠杆；
3. **策略活跃度可控地起来了**：KL 中位 0.051（G1 的 ~2 倍）且 468 步无发散（仅 2 步孤立尖峰后回落）。

### 6.2 下一步

| 优先级 | 事项 | 判据 |
|---|---|---|
| **P0** | 四档汇总 T4（G1'' pred → `eval_four_tier.py`） | SFT→SFT+GRPO 单变量差值落表 |
| P1 | G2（β_KL→0）消融，基线 = G1'' 配置 | KL 必要性实证；reward hacking 观察位 |
| P2 | G3（lr 5e-5）消融 | 门禁短路占比为主信号 |
| P3 | G5c（risk 部分匹配档） | risk SubAcc +1~3pp 预期 |
| 收口 | G6 训后 k 分布迁移 | k=0 下降 / k=4 上升 = 「把不会的学会了」 |
