# 四档对照实验补全计划

> 配套 `SFT对照实验_设计清单_20261027.md`：原清单只覆盖 T1/T3，本计划补 T2、T4 两档。
> 评估脚本：`scripts/eval_four_tier.py`。变量锁定沿用原清单
> （`NPROC=1 THINK_PREFIX=0 UNFREEZE_PROTOCOL_TOKENS=1`）。

## 四档 ↔ 原清单枪位映射

| 四档 | 枪位 | pred 文件 |
|---|---|---|
| T1 裸基座 | E3（原清单） | `output/e3_base_pred.jsonl` |
| T2 提示词加固 | E3b（本计划） | `output/e3b_prompt_pred.jsonl` |
| T3 SFT | R1~R5 胜者（+R6 若达标），软链 `output/pred_sft.jsonl` | 胜者 run 目录 |
| T4 GRPO | G1（本计划，R6 出口决策后启动） | `output/pred_grpo.jsonl` |

四档共用 gold：`data/gold500_test.jsonl`，行序必须严格对齐，否则整档记 missing。

## E3b · T2 提示词加固

不训练，紧跟 E3 跑，几分钟。基座 + few-shot 推理，拿「提示词天花板」，
为「为什么堆 Prompt 不够、必须微调」提供实测证据。

```bash
python3 scripts/sft_infer.py \
  --base_model "$MODEL_DIR/Qwen3-4B-Instruct-2507" \
  --adapter_path '' \
  --data_file data/gold500_test.jsonl \
  --few_shot_file data/few_shot_examples.jsonl \
  --out output/e3b_prompt_pred.jsonl

python3 scripts/evaluate_sft.py \
  --gold_file data/gold500_test.jsonl \
  --pred_file output/e3b_prompt_pred.jsonl
```

前置：手工构造 `data/few_shot_examples.jsonl`（2~3 条典型难例 + 空表样本，
从训练集手选，严禁用 gold500）。`sft_infer.py` 若无 `--few_shot_file` 参数则加一个。

判读：若 T2 接近 T3，R6 的「增益 <2pp 转 GRPO」判据要结合 T2 读，
别把提示词能拿到的分记成 SFT 功劳。

## G1 · T4 GRPO 占位

R6 增益 <2pp 时启动（原清单已定）。SFT 胜者的 STAGE/LR/EP 全锁死，只加 RL LoRA。
推理产物落 `output/pred_grpo.jsonl`。GRPO 训练超参与 reward 分析另立清单，不在本计划。
T4 未跑时 `--pred_grpo` 省略，记 missing，其余档照常出数。

## 四档汇总（全部枪跑完后一次）

```bash
ln -sf <胜者run目录>/pred.jsonl output/pred_sft.jsonl

python3 scripts/eval_four_tier.py \
  --gold data/gold500_test.jsonl \
  --pred_base  output/e3_base_pred.jsonl \
  --pred_prompt output/e3b_prompt_pred.jsonl \
  --pred_sft   output/pred_sft.jsonl \
  --pred_grpo  output/pred_grpo.jsonl \
  --out output/tier_report.json
```

产出 `tier_report.json`（四档 × 指标 + 单变量差值归因），回填数字清单 §6。
